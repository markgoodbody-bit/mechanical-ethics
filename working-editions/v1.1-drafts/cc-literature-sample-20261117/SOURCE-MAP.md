## Earlier project work recovered

COM [`open-horizon/positive-construction.md`](https://github.com/markgoodbody-bit/COM/blob/main/open-horizon/positive-construction.md) already says that an option "can exist without becoming something an entity can actually use", and that the project learned this from "capability/human-development work, ecological/relational accounts of affordance". COM `research/MIDDLE_OUT_RESEARCH_SCAFFOLD_20260901.md` uses `FORMAL_OPTION != PRACTICAL_AFFORDANCE`, and `research/CHILD_SKILL_FORMATION_CASE_A_20260901.md` §3 treats support as something that "can create an affordance". The child-formation case cites learning-science sources, but none of the three files names a source for capabilities or affordances. A search of the released v1.0 manuscript for Sen, Nussbaum, "capability approach", Gibson, affordance, Juarrero, Snowden and Cynefin found no match. The lineage was known inside the project but dropped from the book; 1.1 should restore it with sources that have actually been read.

## What this map does not establish

It records relations between passages and the sources actually read in this pass. It does not establish that ME's ideas are novel, that they are equivalent to these traditions, or that the unread leads say what their reputations suggest. Read the unread sources before citing them.
