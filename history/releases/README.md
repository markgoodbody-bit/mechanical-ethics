The original v0.8.0 Markdown, PDF and eight figure carriers were **moved as
unchanged Git blobs**, with the figures kept beside the manuscript so its
relative image references continue to resolve. Its deterministic builder and
source integrity workflow still run from the new archive paths. The original
v0.8.0 publication workflow has been retired from active GitHub Actions and
preserved [here](v0.8.0/workflows/release-v080.yml); the existing published
v0.8.0 GitHub Release is not recreated or modified.

**Links using the old unversioned root filenames on `main` may stop working**:
`MECHANICAL_ETHICS.md`, `MECHANICAL_ETHICS.pdf` and `figures/...`.
Prefer the archive links here or the immutable v0.8.0 tag. This reorganisation
does not change the files' content, their historical release decisions,
version-specific permissions or scientific-validation status.
