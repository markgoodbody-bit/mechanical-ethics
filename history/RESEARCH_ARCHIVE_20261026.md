## Source and rights boundaries

- **Do not merge a historical draft into v1.0 by default.** A useful missing idea needs independent source examination, comparison with the current exact manuscript and a distinct editorial decision.
- **Do not alter or discard historical release assets**: root v0.8 Markdown/PDF, `figures/`, tagged releases, release receipts, AI-training notice and Git history are existing controlled carriers.
- **Do not treat publication or successful CI as external validation.** Original draft claims and historical branch titles do not establish efficacy, authorship permissions or scientific correctness.
- **Branches and Git tags were deliberately retained during this review.** Branch deletion is a separate potentially destructive operation, and this recorded SHA inventory is not evidence that a removed Git ref would be permanently recoverable. The index documents current/previous sources even if their UI status changes.
- Source lineage and fixed published v1.0 identities are recorded in [edition provenance](../working-editions/v1.0/PROVENANCE.md).

The purpose of this inventory is practical: **one obvious current book; historical alternatives inspectable when genuinely needed; no accidental re-release of superseded research.**
