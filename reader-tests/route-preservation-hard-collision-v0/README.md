# Route-preservation hard-collision reader test v0

Status: **FUTURE-READER CLARITY TEST / RELEASED v0.7.0 UNCHANGED / NO PRIORITY LAW / NO PARTICIPANT RECRUITMENT**

This test exists because Mechanical Ethics issue #47 identified a plausible reader pressure:

> could the conclusion sentence "Keep at least one genuinely usable route open" be read as a universal satisfiable requirement for every affected being, even in a hard collision where protected paths cannot all continue?

The test does **not** assume the answer.

## Two conditions

### A — isolated imperative

Reader sees only the final practical-demand paragraph.

Purpose:
test the surface meaning of the strongest wording without surrounding qualification.

### B — conclusion context

Reader sees the complete conclusion passage from the account of conflicting protected paths through the practical-demand paragraph.

Purpose:
test whether the nearby explicit qualifier prevents a universal reading.

## Fixed questions

For each condition, answer without using other project documents:

1. Which reading is most strongly licensed by the text?
   - `UNIVERSAL_EACH_BEING`: every affected being must retain at least one genuinely usable continuing route in every responsible decision.
   - `DEFEASIBLE_DEFAULT`: preserving a usable route is a strong practical demand/default, but hard conflicts may make simultaneous preservation impossible.
   - `UNCLEAR`: the text does not settle whether the demand is universal or defeasible.

2. Does the excerpt itself supply a rule for ranking incompatible protected paths?
   - `YES`
   - `NO`
   - `UNCLEAR`

3. Quote or identify the smallest phrase(s) driving your answer.

4. State one plausible misreading a careful editor should guard against.

## Promotion / no-change rule

A wording repair is **earned** only if competent cold readers repeatedly return `UNIVERSAL_EACH_BEING` or `UNCLEAR` under Condition B for reasons grounded in the text.

If Condition B reliably returns `DEFEASIBLE_DEFAULT` and `NO`, the existing conclusion is sufficiently self-defeating and no patch is earned.

Condition A may be ambiguous without, by itself, earning a patch: the book is not normally read as one sentence detached from its paragraph.

## Hard boundary

Do not use this test to invent:
- a biodiversity priority rule;
- a species-ranking rule;
- a population-vs-individual calculus;
- a universal allocation formula.

The question is wording clarity, not moral adjudication.
